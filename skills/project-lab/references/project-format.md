Keep hints ordered from question to cue to partial example to worked example. Hide answers from the default learner view.

## RUBRIC.md

For every competency, define evidence for `guided`, `independent`, and `transfer`. Add system-level criteria for correctness, explanation, diagnosis, and reproducibility.

## EVIDENCE.md

Map each claim to a file, command, trace, recording, or observed response. Record scaffolding. Unsupported claims remain `unknown`.

## POSTMORTEM.md

Record predictions, observed results, important errors, model corrections, trade-offs, and the smallest useful next experiment.
