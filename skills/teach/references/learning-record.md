# Learning record

Name files `NNNN-dash-case-name.md`.

```markdown
# <Insight or demonstrated capability>

- Competency: <competency_id>
- Evidence: <what the learner did without unsupported help>
- Depth: recall | guided | independent | transfer
- Consequence: <how this changes the next lesson>
- Recorded: YYYY-MM-DD
```

Create a record only when the evidence changes the assumed floor of instruction. A claim of familiarity is context; a correct independent use is evidence.
