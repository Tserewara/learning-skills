# Teaching workspace

Create missing paths only when needed:

```text
MISSION.md
NOTES.md
RESOURCES.md
GLOSSARY.md
lessons/
reference/
learning-records/
assets/
```

## MISSION.md

```markdown
# Mission

I want to learn <capability> so that <real consequence>.

## Proof

I will know this mission is advancing when I can <observable behavior>.

## Constraints

- Time:
- Tools:
- Prior experience:
```

## RESOURCES.md

Keep a short annotated list. Record why a source is trusted and which competency it supports. Prefer one primary source per lesson over an unbounded reading list.

## GLOSSARY.md

Use one canonical term per concept. Add a term only when the learner can explain it. Keep definitions short and operational.

## NOTES.md

Record durable preferences and constraints. Do not duplicate learning evidence or session logs.
